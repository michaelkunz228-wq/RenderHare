# Changelog

## 1.0.0 — 2026-09-29

First release.

- Scan the active sequence (and nested sequences) for After Effects Dynamic
  Link clips; live vs already rendered, inside/outside the In/Out.
- Render and Replace per comp or all at once through Premiere's own command;
  the list refreshes when the render finishes.
- Restore Unrendered for rendered clips; click a clip to select it and jump
  the playhead there.
- Works in all 10 Premiere UI languages (labels from Adobe's own dictionaries).
- Windows 10/11; macOS support in beta (untested on hardware).
- Premiere Pro 2026 (26.0) or newer.
